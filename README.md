# Smart Puzzles

Logic puzzle apps with coaching that explains the reasoning behind a move.

## Play all six games

**Studio hub:** https://smartpuzzles.github.io/apps/

Sudoku, Binairo, Crownfall, Zigline, Shikaku and Wordvine are playable in the browser with five interface languages, local progress and explained logical hints. These web editions provide selected starter puzzles. Only Smart Sudoku is currently available on the App Store.

## Smart Sudoku

**Now on the App Store:** https://apps.apple.com/app/id6758866615

**Product and learning pages:** https://smartpuzzles.github.io/sudoku/

- English: https://smartpuzzles.github.io/sudoku/
- 繁體中文: https://smartpuzzles.github.io/sudoku/zh-Hant/

- 日本語: https://smartpuzzles.github.io/sudoku/ja/

6×6 and 9×9 Sudoku, supported logical techniques explained by AI Coach, pencil marks, daily challenges and game customisation. Free to download with optional in-app purchases. Exact Coach access and membership benefits are shown in the app.
